# Источники и права

Авторский код этого приложения распространяется по MIT. База описаний в catalog/features.json и пересказ технических материалов HackAlice в руководстве распространяются по CC BY 4.0. Авторы исходных материалов — Марк Писаренко (hackalice) и участники проекта Yandex Station Extended. Изменения для приложения включают краткие пересказы, группировку по моделям и отдельные условия для проверки на Станции пользователя. [Исходные материалы](https://github.com/Marker284/yandex-station-extended/tree/520fbccd68cb90a8c4f01d06bf38d9a7db915304) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Названия Яндекс, Алиса, Spotify, DeepSeek и других сервисов принадлежат соответствующим правообладателям. Это независимый проект. Исполняемые файлы прошивок, наборы моделей, образы колонок, клиенты сторонних сервисов и иллюстрации производителей в поставку не входят. Владелец устанавливает OpenSSH и Android Platform Tools отдельно по официальным инструкциям. Веб-страницы, на которые ссылается приложение, и отдельные внешние проекты имеют собственные условия использования.
