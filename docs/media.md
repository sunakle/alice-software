# Музыка и команды Windows

**Проверка звука.** Скажи «Алиса, включи Bluetooth». В «Музыке» открой настройки Bluetooth Windows, добавь устройство и штатно заверши сопряжение. Нажми «Обновить выходы», выбери стереовыход Станции и нажми «Проиграть короткий сигнал». До подключения колонки можно испытать динамики ПК. Программа перечисляет реальные выходы WinMM, сохраняет идентификатор конечного устройства Windows и подаёт полусекундный PCM-сигнал непосредственно на выбранный выход. Сигнал остаётся коротким и умеренным по цифровому уровню. Слышимость зависит от системной громкости. При отключении или смене драйвера потребуется обновить список.

**Spotify.** Открой официальный клиент кнопкой «Открыть Spotify». При отсутствии обработчика Spotify откроется официальный веб-плеер. Запусти трек и открой «Громкость приложений». Назначь нужный выход самому Spotify или браузеру с веб-плеером. Слышишь трек именно из Станции — отметь «Подтверждаю, слышу Spotify на Станции». Сигнал этой программы и воспроизведение трека проверяются отдельно. Штатный Bluetooth доступен без root. Нативный Spotify Connect для Лайт 2 с часами не подтверждён. Ключи Spotify приложение не запрашивает. Готовых голосовых команд, управляющих Spotify через Spotify Web API, здесь нет.

**Команда на ПК.** Выбери действие `chrome`, проверь путь к chrome.exe или выбери установленный файл. Задай фразу и синонимы через точку с запятой. Нажми «Сохранить и разрешить», прочитай цель и подтверди. «Выполнить на этом ПК» проверяет фразу и вызывает Windows в текущем сеансе. Поддерживаются выбранный .exe без аргументов, один разрешённый HTTPS-адрес или одна системная медиаклавиша. Медиаклавиша управляет активным плеером по правилам Windows. Исходный путь, фразы, назначение и содержимое исполняемого файла участвуют в привязке разрешения. После обновления Chrome потребуется снова подтвердить изменившийся файл. Импортированные настройки требуют нового разрешения. Файл, на который ведёт символическая ссылка, можно выбрать по исходному пути. Для WindowsApps с особыми системными ссылками выбери обычную установку или HTTPS-адрес.

**Голос.** Для команды с HA используй [инструкцию сопряжения](home-assistant.md) и два YAML-файла из этой папки. Обычный root/SSH сам по себе не пересылает слова с колонки. Альтернативный [навык «ПК Мост»](https://dialogs.yandex.ru/store/skills/0e1c9e99-moj-komp-yute) доступен через штатную Алису и использует собственное приложение.
