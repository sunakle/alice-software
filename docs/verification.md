# Проверка «Пульта Станции» на Windows 10

## Обновление интерфейса 1.1.0

На настоящей Windows проверялись запуск основного окна, переходы между разделами, поиск, история, сворачивание в область уведомлений, разворачивание и возврат к исходному размеру. Для проверки размеров и отступов использовались снимки окон в обычном и компактном размерах. Красная, жёлтая и зелёная кнопки имеют собственные подписи для средств доступности. Установщик и переносимая версия собраны из тех же исходников.

Для повторения визуальной проверки запусти `tests/ui-layout.ps1 -ApplicationPath <exe> -OutputDirectory <каталог>`. Для компактного окна добавь `-Width 880 -Height 620`. Скрипт `tests/window-chrome.ps1 -ApplicationPath <exe>` испытывает кнопки окна, область рабочего стола и возврат к начальному размеру.

## Исходная функциональная проверка 1.0.0

11 ноября 2026 года. Проверочный компьютер — Windows 10 Pro x64 22H2, сборка 19045.6466. Сборка выполнялась системным 64-разрядным компилятором C# 5, csc.exe версии 4.8.9232.0, .NET Framework 4.8.1 (Release 533325) и Windows PowerShell 5.1. Это обычная учётная запись существующей системы, отдельная чистая установка Windows в виртуальной машине не использовалась.

## Что предстоит проверить владельцу

1. **Облачный DeepSeek.** Открыть «Нейросети», сохранить свой ключ, отдельно запросить модели и отправить одну короткую фразу. Для выпуска платный ключ и баланс владельца не использовались.
2. **Музыка.** Подключить Станцию в Bluetooth Windows, прослушать тест, выбрать этот выход для Spotify и включить знакомый трек. В программе вручную подтвердить звук только после прослушивания. Воспроизведение через личный Spotify на физической колонке не испытывалось.
3. **Аппаратная приёмка 00026.** После передачи от друга сверить SSH-отпечаток, снять инвентаризацию и сверить SKU, плату, полную сборку, систему и свободное место. При подходящих признаках сначала проверить короткую фразу, затем один краткий аппаратный тест. Убедиться в возврате штатного состояния и повторить проверку после обычной перезагрузки. Несовместимый адаптер должен объяснить, какого признака не хватает.
4. **Голосовой запуск и ответ.** Настроить HA из приложенных примеров и пройти путь от произнесённой фразы на Станции до события HA, открытия программы и подтверждения. Проверить пропавший ПК, дубликат, отзыв и возвращение штатной Алисы. Для голосовой модели отдельно проверить запрос с хоста моста и услышать ответ на Станции.
5. **Расширения.** YAM, AirPlay, Pulsar, Alisa Voice, микрофон VQE, произвольные сегменты экрана и нативный Spotify Connect зависят от конкретного устройства и внешних проектов. Для части функций поставлена справка. Универсальная установка и изменение загрузчика в этот выпуск не входят.

## Повторение

В корне исходников выполни команду из [README](../README.md). Отчёты основного набора и установщика появятся в dist. Для отдельно запускаемых скриптов используй Windows PowerShell 5.1. Распакуй переносимый ZIP в доступный для записи каталог. Параметр ApplicationPath указывает на извлечённый StantsiyaDesk.exe.

- `tests/ai-smoke.ps1` проверяет клиент на настоящем loopback HTTP, TLS и фикстурах.
- `tests/device-offline.ps1 -AppExe <exe>` проверяет протоколы и защиту копий в обычном профиле Windows.
- `tests/media-windows.ps1 -ApplicationPath <exe>` запускает тестовый файл Windows и испытывает точное совпадение разрешений.
- `tests/ui-layout.ps1 -ApplicationPath <exe> -OutputDirectory <каталог>` сохраняет изображения экранов в новом пустом профиле.
- `tests/owner-chrome.ps1 -ApplicationPath <exe>` открывает настоящий Chrome. `tests/owner-audio.ps1 -ApplicationPath <exe>` перечисляет выходы. Добавь `-Index 0` или другой индекс, чтобы услышать короткий тон.
- `tests/transport-loopback.py` проверяет настоящий OpenSSH и имитацию командной строки ADB. Для этого дополнительного стенда нужны Python, Paramiko и Git for Windows. Обычная сборка и программа работают без них.

Проверка контрольной суммы сравнивает конкретный файл с опубликованным экземпляром. При повторной сборке системный компилятор и ZIP могут проставить новые метки времени. Установщик и переносимый файл этого выпуска не подписаны сертификатом издателя.
