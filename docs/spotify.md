# Музыка по своим фразам — версия 1.4

В хабе можно связать фразу с точной песней, исполнителем, альбомом или плейлистом Spotify. Например, «включи мой вечер» запускает сохранённый плейлист; «включи любимого исполнителя» — страницу исполнителя как контекст воспроизведения. Используется ссылка Spotify, поэтому совпадение названий не приводит к выбору чужого плейлиста.

## Сначала проверь воспроизведение с ПК

1. Открой **Музыка → Spotify и фразы**.
2. В [Spotify Developer Dashboard](https://developer.spotify.com/dashboard) создай своё приложение с доступом Web API. В его Redirect URIs укажи **`http://127.0.0.1:5589/callback`** без завершающего слеша. Если приложение в development mode, добавь нужного пользователя в разрешённые пользователи. Для управления плеером требуется Spotify Premium; доступность Dashboard и API зависит от аккаунта и региона.
3. Скопируй **Client ID** в хаб и нажми **Войти через браузер**. Client Secret и пароль Spotify хабу не нужны. Разреши управление воспроизведением в браузере, затем вернись в хаб. Можно отменить вход кнопкой под настройками; ожидание ограничено тремя минутами.
4. Открой официальный Spotify на компьютере и запусти любой трек. В хабе нажми **Обновить устройства**, явно выбери этот компьютер. Если устройство недоступно, хаб сообщает об ошибке; другую колонку автоматически не выбирает.
5. Во вкладке **Звук и Bluetooth** открой настройки Windows. Подключи Станцию по Bluetooth и назначь Spotify выход на неё в микшере приложений. Выбор выхода пробного сигнала в хабе сам по себе не меняет выход Spotify.
6. Скопируй ссылку из Spotify через «Поделиться», вставь её в поле третьего шага и нажми **Проиграть ссылку**. Проверь фактический звук. Ответ API подтверждает принятие команды, а не слышимость.

## Затем сохрани фразы

1. Нажми **Настроить фразы**, либо открой **Голос и команды → Новая музыкальная фраза**.
2. Введи одну или несколько фраз через `;`, например `включи мой вечер; мой вечерний плейлист`.
3. Выбери тип **Spotify** и вставь ссылку на нужную музыку. ID создаётся автоматически для новой музыкальной фразы.
4. Нажми **Сохранить и разрешить**. Это локальное разрешение на заданную цель; оно не переносится при импорте профиля.
5. Введи одну из фраз в ручную проверку и нажми **Испытать фразу**. Регистр букв, повторные пробелы и конечные `. ! ?` не мешают совпадению. Частичное совпадение не используется.

## Передача голоса через Home Assistant

Хаб не получает речь из штатной Алисы автоматически. Для этого маршрута нужны работающие **Assist, Home Assistant и Windows-хаб**.

1. Проверь Assist текстом в HA. Для экспортированных фраз используй локальное распознавание намерений Home Assistant на русском; если выбран LLM-агент, настрой локальную обработку известных команд.
2. В хабе открой **Голос и команды → Голос через Home Assistant → Экспорт фраз для HA**. Экспорт включает только локально разрешённые команды. Используй фразы без пунктуации, шаблонных скобок и спецсимволов.
3. Сохрани полученный файл как `packages/stantsiya_desk.yaml` в конфигурации HA. В существующем разделе `homeassistant` включи `packages: !include_dir_named packages`. Пакет содержит два `input_text` и одну очередь голосовых команд. Он **заменяет** прежний пример пакета из хаба; не устанавливай две версии с одинаковыми helpers. Если ранее устанавливал старый пример `custom_sentences/ru/stantsiya_desk.yaml`, удали только этот старый файл примера, чтобы не оставлять конфликтующие намерения. Сделай проверку конфигурации средствами HA и перезагрузи её.
4. Подключи хаб к HA по [инструкции](home-assistant.md): HTTPS-адрес с доверенным сертификатом, локальный сетевой интерфейс и отдельный токен HA. Секреты не входят в экспортированный YAML.
5. Введи сохранённую фразу в Assist. Проверь журнал хаба и воспроизведение. После этого проверяй её через голосовой спутник.
6. При изменении фраз/ID, профиля или отзыве привязки повтори экспорт и замени пакет. Для работы в фоне можно включить автозапуск агента при входе в Windows и свернуть хаб в трей. Закрытие программы завершает агент.

## Что ещё требуется проверить именно на Лайт 2

Документация YSE описывает Pulsar для подключения микрофона Лайт 2 к Assist. Он останавливает штатный Quasar. **Одновременную работу такого голосового входа и Bluetooth-вывода Spotify на той же колонке мы не проверяли.** Не считай их совместимость установленной: сначала нужна проверка на твоей прошивке. Временно голос можно подавать из Assist на телефоне, сохранив штатный Bluetooth Станции.

Нативный Spotify Connect на Лайт 2 в таблице YSE обозначен как непроверенный. Эта версия хаба не устанавливает на колонку librespot и не обещает автономное воспроизведение при выключенном ПК. Для законченного автономного режима потребуется отдельный совместимый проигрыватель на колонке и проверка его совместной работы с голосовым стеком.

Настройки API нейросетей и Windows-голоса остаются в разделе **Нейросети**. Голос Assist настраивается в HA; голос Windows и голос самой Станции — разные маршруты.

## Ошибки и хранение

- **403:** проверь Premium, доступ Web API и разрешённого пользователя приложения.
- **404 / нет устройств:** открой официальный Spotify, запусти трек, обнови список и выбери устройство заново.
- **429:** подожди указанное Spotify время. Автоматического цикла повторных команд нет.
- **Истёк вход:** хаб обновляет токен; при отказе войди заново.
- **Потерян ответ после отправки:** проверь, играет ли музыка, перед повтором. HA получает `unknown`, а не ложное подтверждение.

Токены сохраняются через Windows DPAPI для текущего пользователя и профиля. Они не включаются в экспорт профиля и YAML, не выводятся в журнал. Кнопка **Выйти** удаляет локальные токены; для полного отзыва доступа используй страницу приложений в аккаунте Spotify.

## Источники и проверки

- [Spotify: PKCE](https://developer.spotify.com/documentation/web-api/tutorials/code-pkce-flow), [Redirect URI](https://developer.spotify.com/documentation/web-api/concepts/redirect_uri), [управление плеером](https://developer.spotify.com/documentation/web-api/reference/start-a-users-playback), [ограничения приложения](https://developer.spotify.com/documentation/web-api/concepts/quota-modes).
- [Home Assistant: голосовые команды](https://www.home-assistant.io/integrations/conversation/).
- [YSE: Лайт 2](https://hackalice.me/devices/station-lite2/), [голосовой спутник и ограничения совместимости](https://hackalice.me/recipes/home-assistant/).

Автоматические проверки используют поддельные HTTP-ответы Spotify и временные профили. Они проверяют формирование запросов, токены, отказы, сохранение и экспорт. Вход с настоящим аккаунтом, живой HA, звук и прошитая колонка требуют проверки владельцем.
